# Cubo 3D con HTML y CSS

Proyecto individual hecho solo con HTML y CSS. Consiste en un cubo 3D animado usando transformaciones CSS.

## Tecnologías utilizadas

- HTML5
- CSS3
- Transformaciones 3D
- Animaciones con `@keyframes`
- Diseño responsive

## Archivos

- `index.html`: estructura del proyecto.
- `style.css`: estilos, diseño y animación del cubo.
